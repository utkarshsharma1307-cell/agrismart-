Voice Assistant Demo

Voice Assistant Available on All Pages

The voice assistant is now accessible from every authenticated page. Click the microphone button in the header or use the floating assistant widget.

Voice Commands

Use voice commands to navigate and control Agriii without typing.

"soil" → Open Soil Health
"weather" → Open Weather
"crop" → Crop Advisor
"disease" → Disease Detection
"market" → Market Prices
"profit" → Profit Planner
"dark mode" → Toggle theme
"हिंदी" → Switch to Hindi

How to Use

  1. Click the Voice button in the header
  2. Allow microphone access when prompted
  3. Speak your command or question clearly
  4. Wait for the response or navigation

Tip: You can also use the floating assistant widget at the bottom right, or visit the full Assistant page for text chat.

Browser Support

✓ Chrome / Edge (Recommended)
✓ Safari (iOS/macOS)
~ Firefox (Limited)

Voice features use the browser's Web Speech API. Text chat works in all browsers.
